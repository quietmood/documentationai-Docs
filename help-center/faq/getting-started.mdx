## Quick Start

To start organizing docs in Quietmood:

1. Sign up at `https://quietmood.com`
2. Create your first project from the dashboard
3. Click "Add New Page" to begin your docs
4. Invite team members to collaborate

## Tips

- Use folders to keep things organized
- Set permissions in project settings

<Callout kind="info">
Quietmood autosaves your changes.
</Callout>
