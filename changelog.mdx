## How to Upgrade

Follow these steps to update Quietmood to the latest version.

<Steps>
  <Step title="Check Current Version" icon="check-circle">

    View your current version in the dashboard.

    ```bash
    quietmood --version
    ```

  </Step>
  <Step title="Update via CLI" icon="download">

    <Tabs>
      <Tab title="npm" icon="package">
        ```bash
        npm update quietmood
        ```
      </Tab>
      <Tab title="Docker" icon="docker">
````dockerfile
docker pull quietmood:latest
docker-compose up -d
````
      </Tab>
    </Tabs>

  </Step>
  <Step title="Verify Update" icon="shield-check">

    Restart services and confirm the new version.

    <CodeGroup tabs="CLI,Dashboard">
      ```bash
      quietmood status
      ```
      ```javascript
      // Check via API
      fetch('https://api.example.com/version')
        .then(res => res.json())
        .then(data => console.log(data.version));
      ```
    </CodeGroup>

  </Step>
</Steps>

## Known Issues and Resolutions

<ExpandableGroup>
  <Expandable title="Signup form occasionally fails on mobile" default-open="true">
    This affects Safari on iOS 17. Workaround: Use Chrome or update to iOS 18. Fixed in v1.2.1 (upcoming).
  </Expandable>
  <Expandable title="Coupon emails delayed in high-traffic periods">
    Due to email provider throttling. Resolutions: Check spam folder or resend from dashboard. Mitigated in v1.2.0 with queue improvements.
  </Expandable>
</ExpandableGroup>
